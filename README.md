# 运维小工具

一个集成了多种运维常用功能的桌面工具，基于 Python + PyQt5 开发。

## 功能特性

### 文件搜索
- 支持在指定目录或文件中搜索关键字
- 支持文件过滤（如 `*.txt`, `*.log`）
- 支持全词匹配模式
- 多线程搜索，提高搜索效率
- 支持多种编码格式（UTF-8、GBK、GB2312等）

### 进制转换
- 支持十进制、二进制、八进制、十六进制之间的相互转换
- 支持批量转换（每行一个数字）

### 时间戳转换
- 时间戳转日期时间
- 日期时间转时间戳
- 自动识别秒级和毫秒级时间戳
- 获取当前时间

### MD5加密
- 文本MD5加密（支持32位和16位）
- 文件MD5校验

### SQL工具
- 将多行数据格式化为 SQL IN 条件
- 一键复制结果

### 大小写转换
- 转大写
- 转小写
- 大小写互换

### 网络工具
- Ping 测试
- 端口扫描
- 获取本机IP

### IP子网计算
- 输入IP地址和子网掩码
- 计算网络地址、广播地址、可用IP范围等

### API测试
- 支持 GET、POST、PUT、DELETE 请求
- 自定义请求头
- 显示响应状态码、响应时间、响应头和响应体

### 端口转发
- 本地端口转发到目标地址
- 实时日志显示

### 远程下载
- 从远程主机下载文件

### 进程管理
- 查看系统进程
- 结束指定进程

### 服务管理
- 查看系统服务状态
- 启动/停止服务

## 技术栈

- Python 3.x
- PyQt5
- requests
- 多线程/多进程

## 快速开始

### 环境要求

- Python 3.6+
- PyQt5
- requests

### 安装依赖

```bash
pip install pyqt5 requests
```

### 运行程序

```bash
python main.py
```

### 打包成可执行文件

```bash
pip install pyinstaller
pyinstaller -F -w -i icon.ico main.py
```

## 使用说明

### 文件搜索
1. 点击"选择目录"或"选择文件"按钮选择搜索路径
2. 输入搜索关键字
3. 可选：设置文件过滤条件（如 `*.txt`）
4. 可选：点击"全词匹配"切换匹配模式
5. 点击"开始搜索"按钮

### 进制转换
1. 在输入框中输入数字（每行一个）
2. 选择源进制和目标进制
3. 点击"转换"按钮

### 时间戳转换
1. 输入时间戳（支持批量转换）
2. 点击"转日期"按钮
